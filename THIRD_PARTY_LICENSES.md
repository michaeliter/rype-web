The RYpe host filter page (`web/`, published at https://the-miint.github.io/rype/,
where this file is served as `THIRD_PARTY_LICENSES.txt`)
carries code from the projects below, compiled into its two WebAssembly modules
or shipped as JavaScript next to them. This file identifies each one, how it is
used, where it comes from, and reproduces its license text.

**Policy.** Full license text is inlined once for every license under which
code distributed with the page is taken (all permissive: BSD, MIT, Apache 2.0,
zlib, NCSA, CC0, Unicode, Boost). The C and JavaScript components get a section
each. The Rust crates that `rype_mask.wasm` statically links through RYpe's
dependency graph are listed by crate and license in one section at the end,
generated by `tools/crate_licenses.py`; dual-licensed crates are taken under
MIT (or Apache 2.0 when MIT is not offered). The web fonts are loaded from
Google Fonts at run time and not distributed here, so they are identified by
license name and pointer only.

## RYpe

The RY partitioning engine: k-mer containment screening of reads against a
`.ryxdi` index (in the published bundle, a human pangenome built from the 94
HPRC release 1 haplotype assemblies plus hg38, T2T-CHM13 v2.0 and the GENCODE
v47 transcripts). Compiled to
wasm as a static library and called from
`src/mask.c` (`mask_filter`, `mask_classify`).

- Repository: https://github.com/the-miint/RYpe
- Version: branch `michaeliter/wasm32-support` (the-miint/RYpe pull request #30), pinned at
  the submodule SHA in `.gitmodules` / `git submodule status third_party/RYpe`

## minimap2

Short-read second pass: survivors of the RYpe screen are mapped against a
multi-part T2T-CHM13 v2.0 `.mmi` index. Built as `libminimap2.a` with wasm
SIMD128 standing in for SSE2 (`sse2only=1`) and called from `src/mm.c`. The
ksw2 alignment kernels are part of the minimap2 source tree and share its
license.

- Repository: https://github.com/the-miint/minimap2 (fork of
  https://github.com/lh3/minimap2)
- Version: branch `v2.30-miint`, pinned at the submodule SHA in `.gitmodules` /
  `git submodule status third_party/minimap2`
- License: MIT

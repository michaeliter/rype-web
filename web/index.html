Keep the human index in this browser?

RYpe needs an index of the human pangenome, about 1.8 GB. Downloading it once into this browser's private storage means every run starts right away. For short reads, a 9 GB minimap2 index is downloaded the same way during your first run.

Nothing is uploaded, and you can remove the stored files at any time with the Remove link under Index.

If you would rather store nothing, RYpe streams the index from the server on every run, which is much slower.
